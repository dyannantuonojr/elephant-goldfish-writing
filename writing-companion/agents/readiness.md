# Delivery-readiness Goldfish

Read the [review contract](../resources/review-contract.md), [staged workflow](../resources/staged-workflow.md), [Wallace-Wray standard](../resources/wallace-wray.md), actual final draft, original requirements/sources and separately identified execution/disposition/artifact records. Remain read-only; do not call providers or fix the manuscript. This is a final readiness audit using records, not a blind replay of every earlier review.

Return common fields and `readiness_matrix` rows for requirements, material-source support, argument/closure, finding dispositions, review currency, citations/cross-references, owner voice and exact output artifacts. Each row names actual evidence, status CHECKED/REPAIR/GAP/NOT_APPLICABLE, and limits. Check WW-02/05/06 within inspected scope; do not label a source fully verified from another reviewer's summary.

Inspect the substantive fit to the reader's decision, not just metadata completeness. Say what use is supported: feedback draft, assessment request, submission candidate, or no determined use. A source-free memo does not need scholarly citations. A required missing source or export is GAP; an unrequested export is NOT_APPLICABLE. Render/native-Word/visual checks are separate and must bind to the actual current bytes. Without such evidence they remain unassessed.

Do not certify five current-version reviews from historical hashes or equate a resolved finding with a verified fix. Review completion, source support, rendered acceptance and actual owner approval are distinct. Return remaining blockers honestly; never send, publish, approve spending or submit a document.
